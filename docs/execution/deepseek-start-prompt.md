二、必须执行的当前规则

1. 所有门店业务操作都不审批。只有消费退款、充值退款、免单原因必填，其他原因选填。所有成功修改由服务端记录谁、什么时候、改前、改后。
2. 结算成功后锁定应收、实收、付款拆分和收款时间；少收走原单补收，多收／不应收走退款。禁止“更正收款”和直接改余额。
3. 充值退还只能从原充值记录发起充值退款。
4. 结算时选券，服务端校验并计算，结算成功后自动核销并关联原单；禁止顾客详情手动核销和手动改价代替优惠。
5. V1积分商城只换实物，不换券、服务活动或商品活动。
6. 快速开单提交后直接开始服务；普通预约到店后仍手动点开始。
7. 寄养客户端状态只用寄养中／待结算／已完成／已取消；照护只用喂食／遛狗／清扫笼子／其他，每条说明和照片选填。代喂药、送医、代接等选“其他”。
8. 上门喂养到结束日期自动已结束。附近无店提示“附近暂无服务门店”并结束；定位失败让顾客手动选区。负责店停用后按原绑定门店位置转最近有效店，保留原接单人与历史；新店重新确认后可看双方完整联系方式。
9. 一个人同一时刻只能属于一家有效经营门店。手机号相同识别为同一平台账号／顾客；资料冲突提示人工处理，不自动合并。
10. V1不提供跨店Customer档案、宠物服务报告／护理历史或商户私有业务数据导入；唯一例外是顾客明确授权后按01§5与03g§12一次性复制选定的宠物基础档案，不建立持续同步。不得转移Customer关系或复制订单／余额／优惠券／内部备注。跨店顾客风险只按认证手机号匹配。
11. 消费争议、投诉和顾客风险都没有自助申诉，统一提示联系客服。
12. 顾客风险统一包含顾客相关和宠物相关，宠物相关关联具体宠物；由持有`customer_risk.review`权限的Platform Super Admin审核后，才可按授权、真实业务触发、每店每客每自然月3次和逐次审计规则跨店查看。顾客端看不到任何风险记录信息。
13. 第三方证据只分高／中／低，由审核员人工判断。食品问题热度只显示低／中／高。
14. 食品问题由平台直接联系厂家；门店只知悉，不参与核实或厂家沟通。厂家回应由平台录入，审核通过即算回应，不设期限。
15. 未入驻门店投诉标“未入驻”，入驻后可补回应；平台作最终裁决。同批次再次投诉必须有新证据，集中反馈再次触发重新计算提示有效期。
16. 客户端首页禁止顶部Banner，只留唯一门店栏；商品标题“本店推荐”；消费争议用简版卡片。
17. 启动广告最多等2秒，自定义图片最多展示3秒，始终可立即跳过。
18. 补图或改普通说明都不通知；其他服务结果错误一律重新开单。取消／中止后想继续也重新开单。
19. 员工可看本店顾客完整手机号；营业执照仅老板和平台管理员可看。
20. 待办归门店，谁处理记谁，不领取、不转交。历史订单无业绩归属时默认老板，业绩按实际收款减已确认退款。
21. 门店日常经营和老板设置全部在小程序；Web后台只给平台。
22. 积分实物领取门店停用时自动取消、退积分、发重要通知，不让顾客改选门店；实物异常由平台在原单处理，门店无入口。
