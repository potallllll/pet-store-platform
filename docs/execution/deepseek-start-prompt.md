## 使用说明

将下面代码块复制给DeepSeek。默认先交付G0，不直接让它生成全项目。完整执行标准是唯一流程细则，本提示词只是入口，不重复业务规则。DeepSeek没有GitHub或运行工具时，必须如实告知；可由用户提供该SHA下完整文件，不得凭仓库名/聊天摘要猜内容。
