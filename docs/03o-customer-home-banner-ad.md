# 03O 客户端「首页底部微信 Banner 广告」模块

> status: confirmed
> status_scope: full_document
> change_policy: record_required
> parent_stage: 03 客户端微信小程序
> version: V1.0

## 1. 产品定位

V1.0 客户端首页新增一个用于微信广告曝光变现的 Banner 广告位。

该广告位与以下两个概念严格区分：

- 首页顶部品牌 / 生活方式 Banner：属于产品视觉与门店品牌内容，不是微信广告曝光位。
- 激励视频广告：用于 AI 洗护报告、每日签到、养宠顾问等“完整观看后获得权益”的场景。

首页底部 Banner 仅用于曝光 / 点击类广告变现，不发放积分、AI 次数或其他业务权益。

建议统一 placement：

`home_bottom_banner`

## 2. 首页位置

首页最终内容结构中，底部微信 Banner 广告固定放在：

> 精选商品之后 → 微信 Banner 广告横幅 → 底部导航

因此首页视觉顺序为：

1. 顶部门店栏
2. 顶部品牌 / 生活方式 Banner
3. 当前服务
4. 宠物交友
5. 上门喂养
6. 精选商品
7. 首页底部微信 Banner 广告横幅
8. 底部导航
9. 全局养宠顾问悬浮入口

该广告位属于页面正常内容流，不设计成覆盖正文的全屏 / 悬浮遮挡式广告。

## 3. 展示原则

- 使用微信小程序支持的正式 Banner 广告能力接入。
- 广告内容、素材、点击跳转由正式广告 SDK / 平台能力负责，业务前端不得伪造广告素材冒充真实微信广告。
- 广告位宽度适配页面可用宽度；创意实际高度按正式广告组件返回与平台能力适配，不把某一张测试图比例硬编码成业务常量。
- 广告和精选商品之间保持正常模块间距。
- 广告与底部导航 / 安全区之间保留必要间距，不能被 Home Indicator 或底部 Tab 遮挡。
- 养宠顾问悬浮按钮吸附 / 拖动时不得覆盖广告主要可点击区域。

## 4. 加载状态与故障降级

首页底部 Banner 广告必须独立加载，不得成为首页业务成功的前置条件。

至少支持以下状态：

- `disabled`：平台关闭该广告位，不创建正式广告组件。
- `loading`：正在请求广告。
- `loaded`：广告成功加载并正常展示。
- `no_fill`：当前无可填充广告。
- `failed`：加载 / SDK / 网络失败。

规则：

- `loaded` 时展示真实广告。
- `disabled / no_fill / failed` 时广告区域自动收起，不长期保留大块空白占位。
- 广告加载失败不得导致首页白屏、精选商品消失、底部导航失效或其他业务报错。
- 用户刷新 / 重新进入首页时，可按广告 SDK 与平台规则重新尝试加载。

## 5. 调试与环境配置

为了方便开发、联调和后期广告收益调试，该广告位必须配置化，禁止把广告单元 ID 散落硬编码在页面组件中。

至少需要表达：

- placement：`home_bottom_banner`
- enabled
- ad_unit_id / 对应微信广告位配置
- environment（development / test / production）
- load_status
- last_error（开发 / 日志侧使用，不直接把技术错误暴露给普通客户）

开发 / H5 原型允许使用明确标注为“广告调试占位”的 Mock UI 验证：

- 加载成功
- 无填充
- 加载失败
- 广告关闭
- 页面收起后的布局

但正式生产小程序不得把 Mock Banner 当作真实广告上线，也不得用 Mock 曝光数据冒充真实广告平台统计。

## 6. 配置权限

V1.0 建议由 Platform Super Admin 管理平台广告配置，普通 Merchant Owner / Staff 不直接修改平台广告单元 ID。

具体 Web 后台配置页面在阶段 05 Web 管理后台设计时确认，至少预留：

- 首页底部 Banner 开关
- 广告单元配置
- 环境 / 发布配置
- 后续广告统计查看入口（如平台能力允许）

前端不得包含广告平台敏感 Credential。

## 7. 数据与统计边界

- 微信广告平台产生的正式曝光 / 点击 / 收益数据以广告平台可信数据为准。
- 本系统如记录页面级广告加载成功、失败、无填充等运行指标，应与正式广告收益数据分开。
- 不允许前端自行把“组件出现”直接计为可结算广告收益。
- 调试日志不得影响客户业务记录、订单、积分或钱包。

## 8. 与激励广告权益模块的关系

首页底部 Banner 广告不经过 `03m-customer-rewarded-ads.md` 的权益发放流程。

它不会自动获得或发放：

- 每日签到积分
- AI 洗护报告资格
- 养宠顾问提问次数
- 优惠券
- 钱包余额

如果未来新增“点击 Banner 获奖励”等机制，必须作为新的正式需求单独确认，V1.0 不自动实现。

## 9. 故障隔离

首页底部 Banner 广告故障不得影响：

- 当前服务
- 寄养动态
- 宠物交友
- 上门喂养
- 商品浏览
- 预约
- 钱包 / 积分
- 底部导航
- 养宠顾问已有可用额度

广告模块异常时只降级广告自身。

## 10. V1.0 验收场景

### C-HOME-AD-01：广告加载成功

精选商品下方、底部导航上方出现真实 Banner 广告，页面其他模块正常。

### C-HOME-AD-02：广告无填充

模拟无广告填充，广告区域收起，不留下大块空白，首页其他结构不变。

### C-HOME-AD-03：广告加载失败

模拟加载失败，首页不白屏、不阻塞任何核心业务；开发日志可定位失败原因。

### C-HOME-AD-04：广告关闭

平台关闭 `home_bottom_banner` 后，首页不创建 / 不展示该广告，布局自然收起。

### C-HOME-AD-05：悬浮顾问避让

养宠顾问拖动 / 吸附后不得长期覆盖 Banner 广告主要点击区域或底部导航。
