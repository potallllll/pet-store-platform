## 1. 产品定位

V1.0 新增「养宠顾问」AI 聊天能力，用于提供日常养宠知识、护理、饮食、行为等参考建议。

该功能不是线上兽医，不作为医疗诊断、处方或替代线下动物医院。

养宠顾问与 AI 洗护报告属于不同业务能力：

- 可共用平台 AI Provider SDK / 模型配置基础设施。
- 不共用业务状态、次数、广告权益或任务记录。
- 养宠顾问故障不得导致 AI 洗护报告、洗护、寄养、订单等其他业务不可用。

养宠顾问当前是 **Store 级付费权益功能**，不是全平台或 Merchant 级默认开放能力。

---

## 2. 付费门店权益与开放条件

养宠顾问采用门店级 Feature Entitlement 控制。

V1.0 当前 `1 Merchant = 1 Store`，但权益唯一归属仍固定为 Store：`owner_type=store`、`owner_id=store_id`。Merchant 只作为购买、管理和审计主体，不参与替代 Store 的客户端资格判断。未来扩展为一商户多店时，同一 Merchant 下的 Store 也必须分别拥有有效权益。

入口可用至少同时满足：

1. 当前门店存在有效的养宠顾问付费权益；
2. 该权益未过期 / 未停用；
3. 当前门店已将“养宠顾问”对客户开启；
4. 当前 Platform User 已与当前门店建立有效 Customer 关系，并完成使用该功能所需的身份验证；
5. 当前账号未处于被平台限制使用该能力的状态（如后续存在风控）。

如果任一条件不满足：

- 客户端不展示可用的养宠顾问悬浮入口；
- 不允许仅通过前端修改状态绕过权益校验调用 AI；
- 已存在的历史聊天 / 已解锁额度不应被删除，只是在无资格门店上下文中不可进入使用。

### 2.1 权益管理

建议采用两层开关：

- **平台权益层**：Platform Super Admin 根据门店付费状态授予 / 续期 / 停止 `pet_advisor` 权益；普通 Merchant Owner 不得自行给自己授予付费资格。
- **门店启用层**：在平台权益有效的前提下，Merchant Owner 可选择是否向本店客户开启；无有效付费权益时该开关不可生效。

至少需要表达：

- `owner_type = store`
- `owner_id = store_id`
- `purchaser_merchant_id`（购买、管理和审计关联，不作为资格归属）
- `feature_key = pet_advisor`
- `entitlement_status`
- `enabled_by_merchant`
- `starts_at`
- `expires_at`（可选）
- `plan / source`（后续付费方案阶段确定）

具体收费金额、套餐、续费方式和支付渠道在后续平台商业化 / Web 后台阶段确认，不在本文件写死。

### 2.2 多门店上下文

同一个 Platform User 如果同时是多个门店的 Customer：

- 当前门店有有效权益且已开启 → 显示并允许使用；
- 当前门店未购买 / 已过期 / 已关闭 → 不显示可用入口；
- 从付费门店切换到非付费门店时，入口必须按新的 `store_id` 立即重新校验，不能按 `merchant_id` 或上一门店缓存继续沿用可用状态。

门店 A 购买该功能不得自动让门店 B 的客户上下文获得使用资格。

## 3. 全局悬浮入口

在**符合第 2 节资格条件**的客户端主要页面提供「养宠顾问」悬浮入口。

交互：

- 默认初始位于左侧安全区域。
- UI 已确认采用圆形悬浮按钮作为默认形态。
- 支持用户拖动。
- 拖动过程中可在页面安全区域内自由移动。
- 松手后自动吸附到距离更近的左侧或右侧边缘。
- 不得遮挡微信右上角系统胶囊、底部导航、首页底部 Banner 广告和固定主要操作按钮。
- 可记录用户上次纵向位置，后续进入页面时按安全区重新限制位置。
- 提供可见的“调整位置”操作，再选择“移到左侧 / 移到右侧 / 重置位置”，支持无需拖动完成布局调整；与 10a 通用可用性规格保持一致。

未开通门店不得仅显示一个“付费后可用”的客户侧悬浮按钮制造误导；门店购买 / 开通入口属于老板端 / Web 商业化流程。

## 4. 介绍弹窗

用户首次进入养宠顾问时先展示介绍弹窗。

标题建议：`养宠顾问介绍`

核心说明至少表达：

> 基于 AI 为您提供日常养宠知识、护理、饮食与行为相关参考。AI 内容仅供日常养宠参考，不作为医疗诊断；宠物出现明显异常时，请及时联系专业兽医。

关闭 / 确认后进入聊天界面。

后续可在聊天页提供“关于养宠顾问”入口重新查看介绍，不要求每次进入都强制弹窗。

---

## 5. 聊天界面

至少支持：

- 用户文字提问
- AI 文字回答
- 发送中 / 生成中状态
- 失败重试
- 当前免费 / 已解锁提问次数提示（不得过度打扰）
- 广告解锁入口

具体是否支持图片提问、语音、联网检索等能力后续单独确认，V1.0 不自动推断实现。

每次进入 / 发送问题前，服务端都必须以当前 `store_id` 对应的 Store 权益为准校验可用性，不能以 Merchant 权益替代，也不能只在首次打开页面时检查一次。

---

## 6. 免费次数与广告解锁

本次付费门店权益变更**不改变**此前已确认的问答额度口径。

每个 Platform User：

- 第 1 次有效提问：免费
- 第 2 次有效提问：免费
- 第 3 次有效提问：免费
- 第 4 次有效提问前，需要完整观看一次激励广告
- 每完整观看一次有效广告，解锁 3 次有效提问
- 3 次用完后，再观看一次广告解锁下一组 3 次

前三次免费额度按 Platform User 账号累计，不按日重置，也**不因进入不同付费门店而重新赠送前三次**。

门店权益决定“当前能不能进入 / 使用养宠顾问”，用户额度决定“进入后是否需要广告解锁下一组提问”。两者必须分开判断。

---

## 7. 什么算一次有效提问

只有满足以下条件才消耗 1 次提问额度：

- 用户成功发送问题；且
- AI 服务成功返回有效回答。

以下情况不得消耗次数：

- AI Provider 超时
- AI 调用失败
- 网络中断导致未获得回答
- 系统错误
- 重试动作本身
- 打开 / 关闭聊天页面
- 系统提示消息

广告已经完整观看并成功获得 3 次额度后，即使随后 AI 服务故障，也不得要求用户为同一批额度再次观看广告。

如果用户离开付费门店上下文或门店权益失效，尚未用完的个人额度保留，但在重新进入符合资格的门店前不可继续调用养宠顾问。

---

## 8. 广告权益边界

养宠顾问使用统一激励广告权益模块，placement：`pet_advisor`。

一次有效广告完成只授予养宠顾问 3 次问答额度，不自动授予：

- AI 洗护报告查看资格
- 每日签到资格
- 其他广告奖励

广告解锁前后均必须满足当前门店养宠顾问权益有效；无付费门店资格时不得通过直接调用广告 placement 绕过门店功能权限。

具体广告验证与幂等规则见 `03m-customer-rewarded-ads.md`。

---

## 9. 医疗安全边界

养宠顾问应主动避免把 AI 输出包装成兽医诊断。

当用户描述明显紧急风险时，应优先展示不依赖广告额度的基础安全提示，例如出现：

- 呼吸困难
- 持续抽搐
- 大量出血
- 意识异常
- 其他明显危急状态

此类基础安全提示不应因为用户没有剩余提问额度而被完全阻断。

进一步 AI 咨询仍按正常门店权益 + 用户额度 / 广告规则执行。

---

## 10. 数据与隐私

- 用户聊天记录属于平台级个人数据，不归某一家 Merchant 所有。
- 门店付费只授予本店 Customer 在本店上下文使用该功能的资格，不代表 Merchant Owner / Staff 自动获得客户聊天内容查看权限。
- 不得因为用户在某门店上下文使用顾问，就自动把聊天内容公开给该门店。
- AI Provider 调用只发送完成当前回答所需的最小信息。
- 密钥、Provider 配置等仅保存在后端。

聊天历史保留周期、删除规则和是否支持跨设备同步在后续隐私 / 数据保留阶段进一步确认。

---

## 11. 故障隔离

养宠顾问或权益校验故障不得影响：

- 客户端首页其他区域
- 预约
- 洗护 / 美容
- 寄养
- 商品
- 钱包
- 上门喂养
- AI 洗护报告

客户端应局部隐藏 / 禁用顾问或提示“养宠顾问暂时不可用”，不得导致整页白屏。

## 12. V1.0 关键验收场景

### C-ADVISOR-01：付费门店入口

- 当前门店有有效付费权益且已开启 → 显示圆形悬浮入口。
- 当前门店无权益 / 已过期 / 已关闭 → 不显示可用入口。

### C-ADVISOR-02：跨门店切换

同一用户从已开通门店切换到未开通门店后，入口立即消失；切回符合资格门店后按服务端状态恢复。

### C-ADVISOR-03：首次介绍

首次点击先看到养宠顾问介绍，关闭后进入聊天框。

### C-ADVISOR-04：前三次免费

同一 Platform User 账号前三次有效 AI 回答无需广告；切换到另一付费门店不重新赠送前三次。

### C-ADVISOR-05：广告解锁

第 4 次前要求完整观看广告；成功后获得 3 次有效提问额度；当前门店必须仍有有效顾问权益。

### C-ADVISOR-06：AI失败不扣次数

AI 超时 / 报错后额度保持不变，广告已获得的额度也不会丢失。

### C-ADVISOR-07：门店无法越权查看聊天

普通 Merchant Owner / Staff 不因门店购买养宠顾问而自动看到客户 AI 聊天正文。
