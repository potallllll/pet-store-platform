# 10A 客户端 UI Design System（提前进行的客户端子阶段）

> 状态：已确认基线，持续补充
> 所属阶段：10 UI / Design System（与阶段04并行）
> 当前范围：客户端通用视觉、共享Token、组件、状态、可用性与适配
> 版本：V1.0

## 1. 文档职责

本文件是客户端通用视觉与共享组件规范的唯一来源。首页专属结构、尺寸和组件应用见10b；启动封面广告视觉见10c；页面地图与验收编号见03i；业务规则以03a～03m、03o、03p及对应权威模块为准。03n仅为历史迁移索引。

本文件不得修改财务、权限、多租户、订单、库存、广告权益或门店付费资格。正式代码建立一个共享Token源映射至WXSS及H5，组件只引用语义Token。临时H5/AI图仅供沟通，不自动成为正式需求。通用Token调整必须记录变更并重新验证；不另建竞争的DESIGN.md。

## 2. 客户端整体视觉方向

### 2.1 设计气质

高级、亲和、温暖、生活方式感、轻盈、精致。主基底浅米白/奶油白/暖灰白，卡片白色或极浅暖色，主要强调柔和杏橙/浅金棕，文字深棕灰。宠物及生活方式图片承担情绪价值；轻边框、极轻阴影，避免厚重卡片、医疗化、后台化、过甜促销风或紫蓝霓虹AI风。状态允许小面积低饱和蓝、绿、灰，不重新形成绿色品牌基底。正式图标统一圆角线性/轻量体系，不直接使用Emoji。

### 2.2 通用原则

强调色用于主操作、价格、积分、重点状态与少量引导。清晰的信息层级优于复杂装饰，不通过高饱和红绿堆叠促销。必要控件、状态和金额必须清晰可读；不能为了参考卡高缩小字号或截断核心业务动词。

系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。不为装饰下载外部字体，避免首屏字体替换。字号为375px设计基准，支持用户字号放大，不设固定文本容器高度。

| Token | 字号/行高/字重 | 用途 |
|---|---|---|
| type.hero | 28/36px/700 | 完整品牌Banner标题 |
| type.title | 20/28px/600 | 门店名、页面标题 |
| type.section | 16/24px/700 | 模块、服务卡标题 |
| type.body | 16/24px/400 | 详情正文、输入、长说明 |
| type.body.small | 14/20px/400 | 卡片日期、状态说明 |
| type.caption | 13/20px/400 | 时间、副标题 |
| type.label | 12/18px/500 | 非交互短标签 |
| type.button | 14/20px/600 | 按钮、链接、轮播控制 |

正文、报错、金额和关键状态不得为固定高度缩小字号。放大字号时行高同步增长、中文自然换行，长数字/英文安全断行。摘要可省略，完整重要内容须在详情或明确展开入口可读。

**统一逻辑单位为px。** 以下值不是物理像素，不因320px窄屏等比缩小字体、边框或热区。布局宽度可按rpx适配，特殊业务尺寸须单独声明缩放方式。硬性验收、默认Token和参考尺寸区别见2.8。

| Token | 375px基准值 | 用途 |
|---|---|---|
| space.1/.2/.3/.4/.5/.6/.8 | 4/8/12/16/20/24/32px | 4px栅格，页面边距space.4、模块间距space.6 |
| space.dense.label/.card/.inset | 6/10/14px | 小标签间距、三列卡间距、紧凑卡内边距 |
| radius.control/.card/.hero/.pill | 12/16/20/999px | 控件/普通卡/品牌Banner/胶囊 |
| stroke.control | 1px | 必要控件边界 |
| focus.width/.offset | 2/2px | 焦点宽度/偏移，使用brand.strong，必要时加surface隔离边 |
| target.min | 44×44px | 项目最小实际逻辑触控热区 |

### 2.6 按钮与反馈统一规则

| 意图 | 默认 | 按下/焦点 | 不可用/忙碌 |
|---|---|---|---|
| 主操作 | brand.fill + brand.ink + brand.strong边界 | brand.pressed；统一焦点 | disabled.fill+原因；保留尺寸 |
| 次操作 | surface+text.primary+border.control | neutral.pressed+brand.strong边界 | 同上 |
| 文本链接 | brand.strong，正文内有下划线 | brand.tint背景，焦点可见 | 不触发操作，说明原因 |
| 危险确认 | danger.ink背景+surface文字 | 明确边界/焦点 | 保留对象及后果说明 |

成功、提示、警告、错误均有文字与语义图标；警告可复用brand.tint/strong。浅杏色主按钮不配白色小字；brand.strong在brand.fill上仅作边界，不代替brand.ink小字。同类操作统一文案、状态和反馈；忙碌时不改变宽度、不重复跳转。重试、取消和幂等以业务模块为准。

普通文字至少4.5:1，大字至少3:1；必要非文本控件边界、图标和焦点至少3:1。装饰边框不承担控件识别。依据WCAG2.2文字及非文本对比度说明。静态不透明sRGB组合已于2026-09-08计算，以下为原基线保留值（四舍五入）：

|---|---|---|
| text.primary / canvas；surface | 13.102；14.482 | 通过 |
| text.secondary / canvas；surface | 5.839；6.454 | 通过 |
| text.muted / canvas；surface | 4.878；5.392 | 通过 |
| brand.ink / brand.fill；pressed | 6.387；5.315 | 通过 |
| brand.strong / canvas；surface；tint | 6.553；7.243；5.879 | 通过 |
| text.primary / surface.subtle；neutral.pressed | 12.034；10.436 | 通过 |
| text.secondary / disabled.fill | 5.262 | 通过 |
| accepted/info/success/neutral文本与各自底色 | 6.370/6.730/6.269/5.527 | 通过 |

### 2.8 规范等级与尺寸解释

- **硬性验收约束**：业务/权限/安全不变量、最小热区、必要文字完整、可访问替代、无横向页面溢出等，不能靠视觉参考豁免。
- **默认设计Token**：颜色、字号、间距、圆角、动画与恢复间隔。当前已确认，后续可经正式UI变更调整，不是永远不可修改的业务常数。
- **布局参考**：某页某卡建议高度、图片比例、列宽等，由10b/10c定义。不得使用“参考最小”混合措辞；明确默认高度、真正下限或min-height，长内容自然增高。

750rpx网格仅用于适合缩放的布局：设计375逻辑px时1px对应2rpx；实际宽度W时1rpx=W/750px。实际触控热区、字体、细边框和安全区不全按rpx缩小。

## 3. 首页应用边界

首页完整结构、顶部消息、品牌Banner、有服务紧凑变体、当前服务、宠物交友、上门喂养、精选商品、底部微信Banner、导航及顾问避让由10b唯一规定。首页业务顺序与入口由03i规定。10a不再重复维护第二套首页状态、卡片高度、热度或业务规则。共享组件仅按本文件Token实现，首页采用10b的布局参数。

## 4. 共享卡片与文字组件

卡片统一使用radius.card、surface及必要边界；标题、正文、标签按对应type token，不针对业务另设字号。数据/资产卡只承担展示层级，资金、积分、券的归属与计算由业务模块决定。图文卡媒体先预留比例，加载失败有真实替代说明。状态标签使用共享尺寸、字体、语义色；长状态允许自然换行或独立文本条，不能截断关键状态、金额、地点或操作。

## 5. 共享按钮与表单

按钮区分主、次、文本、危险，页面优先一个真实主操作；具体业务可有多个必要动作，不以视觉规则删除业务按钮。输入、选择器、日期、数量、文本域支持清晰标签、错误说明、忙碌禁用、焦点与键盘。字段错误保留输入并定位首个错误；中文组字期间不触发远程查询。按钮文案完整，外层热区不得重叠。

## 6. 共享列表、空状态与媒体

列表按业务采用分页或加载更多；搜索、筛选与阅读位置在安全上下文内恢复。Loading、Empty、No Results、Error、Disabled不得互相伪装。媒体比例加载前保留，失败显示真实替代、重试或详情入口；完整素材不得由缩略图冒充。已失效公开授权的媒体按权限优先处理，不为布局稳定继续展示。

## 7. 共享轮播与滑动组件

多屏且无暂停条件时默认自动轮播，单屏不自动播放。支持手动滑动、上一屏/下一屏、页码、显式暂停/继续。自动间隔与恢复等待使用2.5节Token。手势、焦点、弹层、离屏、后台、减少动态效果等暂停原因按03h§2.2；显式暂停不能被空闲恢复覆盖。动态数据刷新不得复制内容凑页，权限失效先移除/遮蔽再恢复锚点。首页实际卡数、本人位置和标签仍以03h/10b为准。

## 8. 共享弹层与导航

弹层允许长内容滚动，操作保持可达；底部安全区只补偿一次。页面路由、深链和身份恢复以03g/03p/03i为准。导航不得因广告或辅助模块故障阻塞业务。主要操作、广告点击区域与顾问避让以10b/10c规定的真实组件尺寸处理。

## 9. 共享金额、资产与数据展示

金额使用清晰数字层级和统一货币格式；不得因空间不足裁切关键金额。资金卡、券、积分属于不同业务域，UI不推导或修改财务结果。加载失败不得显示成零余额、零积分或无库存。金额与业务状态以服务端权威结果为准；任何展示变更不能无痕改写历史记录。

## 10. 共享错误、忙碌与恢复

关键业务提交提供状态、稳定请求标识及可查询结果；响应丢失先查询/同次重试，不自动新建。按钮忙碌时保持尺寸和输入。异步旧响应不能覆盖新查询、新门店。通知、广告、AI及统计局部故障不导致核心页面白屏；核心交易不能在一致性未成立时假装全部成功。具体状态机与退款/补偿以业务模块及阶段06为准。

## 11. 养宠顾问通用交互

顾问作为条件式共享悬浮组件，使用圆形默认形态、brand.fill/ink、radius.pill与target.min。可拖动并最近边缘吸附，另提供可见“调整位置→移到左侧/右侧/重置位置”替代；减少动态效果立即定位。不得遮挡系统区、导航、主要操作或广告。具体资格仅以03l服务端校验，位置与首页避让按10b；本文件不定义门店付费或问答额度。

## 12. 底部导航共享表现

统一圆角线性图标、选中brand.strong、未选中中性文字、实际热区至少target.min。底部安全区适配一次，不使用高耸中央悬浮首页按钮。一级导航及业务入口以03i为准，布局尺寸在页面专项规格中定义。

## 13. 状态、错误与故障隔离

### 13.1 统一异步与页面状态

| 状态 | 展示 | 恢复/操作 |
|---|---|---|
| 首次Loading | 模块内提示，结构已知时用最终几何一致的Skeleton | 导航可用，媒体预留比例，超时进入局部Error |
| 刷新/下一页 | 保留已验证数据，局部更新中 | 不整页替换Skeleton、不重置阅读位置，旧响应不覆盖新结果 |
| Empty | 查询成功且确无数据 | 说明暂无与下一步；按业务区分本地空/平台全空 |
| No Results | 保留搜索/筛选 | 提供清空与重置，不等同Empty |
| Local Error | 局部失败、重试，已有数据提示更新失败 | 只重试失败模块，保留安全输入；不伪装零资产/无服务 |
| Disabled | 明确不可操作及原因 | 不响应提交，Toast不是唯一说明；须隐藏的资格入口仍按业务隐藏 |
| Submitting/Busy | 原控件内显示忙碌，尺寸稳定 | 防重复，成功读权威结果，未知结果查询原请求而不新建 |

无单独策略的普通读取请求客户端等待上限10秒，到时局部重试；迟到响应按请求版本处理。业务提交超时/恢复以对应模块为准。切店清除旧店敏感展示并加载新店，旧缓存不能充当新店结果。广告无填充的正常收起不展示业务错误。

字段错误中文说明并保留输入，提交定位首个错误字段。搜索非空提供清空按钮，中文组字期间不发远程查询。成功Toast仅为补充，资金/订单/积分等关键结果留在可重新访问页面。列表返回保留同店筛选和滚动位置，门店/权限变化先校验再恢复。

### 13.2 小程序适配、长内容与安全区

- 375px为设计逻辑宽度，750rpx网格用于布局；字体、细边框、热区和安全区不全部等比缩小。
- 覆盖320/375/430px，至少320×568、375×812、430×932；分别验证100%、150%、200%文字缩放。小程序实际字号档位与H5缩放分别验证。
- 字号不低于对应角色Token基线，不为固定卡高缩小。长名称/状态/日期自然增高；摘要可省略，金额、业务状态、必要错误和按钮文字完整。
- 底部占位包含实际导航/固定栏及安全区，不重复叠加系统已预留空间。顶部按实际系统状态区/微信胶囊避让，不硬编码统一刘海高度。
- 键盘出现按可视区域重排，输入、错误与提交/关闭可达；允许自然纵向滚动，不锁死高度。弹层长正文独立滚动，操作仍可达。
- 媒体加载前预留比例；异步插入/广告收起尽力保留稳定阅读锚点。全屏广告、媒体、弹层或键盘使顾问无安全位置时临时隐藏，恢复后重新校准。

### 13.3 非拖动操作与动态效果

每组护理前后对比必须保留独立拖动，并提供可点击的“护理前 / 护理后”切换；并排查看可额外提供。显示当前组、素材时间及前后标签，缺素材只展示真实素材。控件具备可访问名称、焦点与键盘操作。

顾问提供可见调整位置菜单、左右移位及重置，不只支持拖动或悬停。我的→账号与设置提供减少动态效果选项；支持时默认跟随系统偏好，无法读取时保留用户选择。减少动态效果关闭自动轮播与非必要位移动画；显式暂停后刷新/返回不自动继续，只有用户选择继续才解除。继续按钮自身焦点不立即造成重新暂停，后续焦点进入其他卡片/控制时重新暂停；具体按03h。

### 13.4 权限失效与稳定布局的优先级

权限和隐私优先于动画及阅读位置。公开授权失效时先停止相关交互、遮蔽/移除失效内容、取消当前手势，再尽力按稳定对象恢复阅读位置；对象不存在时转到最近有效页或安全空态。无法保留锚点也不能继续显示失效内容。

纯装饰性Banner更新可等触摸结束、不改变当前可见业务按钮位置的安全时机，或离开模块后再更新。业务安全状态、门店切换和权限撤销不为等待安全动画而延迟生效。异步回调不得覆盖新的门店、权限或已恢复的业务目标。

### 13.5 设计验收

覆盖本节视口/字号、长门店及宠物名、长状态与报错、键盘、单模块失败、搜索无结果、旧响应、重复提交、广告收起、顾问移位、轮播暂停、前后点击替代与权限失效。检查内容完整、阅读/焦点顺序、实际热区、媒体占位、颜色组合。原型/正式范围、证据与验收ID统一按03i§14.1～14.3。静态配色计算不等于整套真机/H5验收通过。
