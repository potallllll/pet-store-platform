# 10B 客户端首页 UI 最终设计规格

> 状态：已确认基线，持续细化
> 所属阶段：10 UI / Design System（与阶段04并行）
> 版本：V1.0

## 1. 文档职责

本文件只定义客户端首页专属布局、信息权重、尺寸参考、Banner变体和广告位置。通用颜色、字体、间距、圆角、热区、动效与可访问性只引用10a，不另设竞争Token。业务状态、权限、金额、广告权益及多租户规则以03系列权威模块为准；页面地图与验收编号以03i为准。启动封面广告由03p/10c负责，不计入首页高度，结束后恢复原业务目标，无目标才首页。

## 2. 首页最终结构

顶部门店栏 → 顶部品牌/生活方式Banner → 当前服务 → 宠物交友 → 上门喂养 → 精选商品 → 首页底部微信Banner广告 → 底部导航。满足门店付费权益条件时另显示全局养宠顾问悬浮入口。业务优先级为当前服务、宠物交友、上门喂养、顶部品牌Banner、精选商品、底部曝光广告；广告不得通过遮挡业务获得曝光。

底部一级导航固定预约/首页/我的。顶部品牌Banner不是微信广告；启动封面发生在首页之外；曝光广告不发积分或AI权益。

## 3. 页面栅格与间距

375px逻辑宽度为参考，320/375/430px及短屏、大字号按10a§13.2适配。页面左右边距space.4，顶部安全区下首内容space.3，主模块space.6，紧凑Banner与服务space.4，标题内容space.3，卡内space.4/紧凑space.dense.inset，横向卡间space.dense.card，小标签space.dense.label，按钮space.2。通用数值仅在10a登记，不在本页重复写死；逻辑px、rpx和硬性热区按10a§2.8处理。

## 4. 顶部门店栏

默认高度52px，内容/字号放大时可增高。左侧可用32×32px门店头像、名称及可选轻副标题。名称type.title，推荐10字内但不限制数据长度，省略时可从门店详情/切换入口读全名。副标题type.caption，正常最多一行，空间不足优先省去。右侧只保留消息，视觉按钮约40×40px、真实热区至少target.min，避让微信胶囊；未读可红点/数量。不同时放搜索或扫码。

## 5. 顶部品牌 / 生活方式 Banner

### 5.1 尺寸与变体

宽度填满内容区，圆角radius.hero。无当前服务时完整变体**默认高度164px**；有服务或尚未查看完成结果时紧凑变体**默认高度72px**，短屏可使用单行品牌条，最小高度48px。必要文字、图片和操作完整时可自然增高，不能以固定高度裁切内容。当前服务优先于装饰。

完整变体375px参考文案区42%、图片区58%，窄屏/大字可调整比例或上下排。必要文字放在10a已验证的不透明底色上，图片独立裁切，不直接叠未知明暗照片。

### 5.2 文案与轮播

完整标题type.hero，正常推荐两行、8～12字；副标题type.caption，正常最多一行，空间不足可省略。CTA视觉高度约34px，真实热区至少target.min，推荐4～6字且完整显示。示例“陪伴 / 让生活更温暖”。紧凑变体使用type.section短标题，省去副标题和非必要CTA，不抢当前服务主操作。

完整品牌Banner最多3张，单张不自动播放，多张复用10a的间隔、暂停/继续、离屏、手势和减少动态效果规则；紧凑变体只展示一张，不自动换图。

### 5.3 变体选择与稳定性

服务查询确认存在进行中或未真正查看结果的刚完成服务时用紧凑变体；确认无服务时用完整变体，预约引导仍在服务区域。首次查询未完成/失败使用紧凑占位，不能把错误当无服务展开。刷新保留已验证变体和安全内容，失败只在服务模块提示。

首次展示前尽量确定变体。已滚动/触控/阅读时，纯装饰性Banner更新可等安全时机且不改变当前可见业务按钮位置，或离开模块后更新；权限与安全变化仍立即处理，不为布局稳定保留失效内容。优先级按10a§13.4。

## 6. 当前服务

### 6.1 卡片尺寸

洗护/美容默认最小内容高度148px，寄养164px；这是正常字号的布局参考下限，不是固定高度或最大高度。长文字/大字号自然增高。优先保留宠物、状态及主操作，日期/动态摘要紧随，媒体加载前预留比例，不能移动按钮。

### 6.2 内容

宠物头像参考76×76px。标题type.section，推荐14字内；全名在详情可读。日期、状态、最新动态用type.body.small，非关键时间可用type.caption。动态摘要推荐16字内，可安全省略并由详情提供全文。主按钮视觉高度约38px，热区至少target.min，文案完整。寄养卡必须有日期范围、第几天、最新动态、今日数量、新媒体提示及“查看寄养动态”。首页最多3条，更多进入完整列表；完成卡查看后的退出规则按03i/03d。

## 7. 宠物交友

### 7.1 单卡尺寸

三列宽度为`(实际内容宽度 - 2 × space.dense.card) / 3`。375px、左右16px时约107.7px，320px时约89.3px，不硬编码104px。默认最小内容高度166px，长昵称/标签/大字号自然增高；图片区为与卡宽一致的正方形，加载前保留比例，圆角radius.card。

### 7.2 卡片结构

宠物主图→社交昵称→热度→符合条件时底部浅色“可发送邀请”。昵称推荐4字内，不是数据长度上限；空间不足可省略，详情显示全名。能力标签不是主按钮，完整文字不可截断，可自然增高。热度如“热度286”，不使用爱心/点赞语义，由服务端返回最近7天有效点击及当前门店7日排名。具体有效点击算法以03h为准。

### 7.3 轮播

每屏最多3只，一轮最多12只真实不同宠物；少量数据按实际数左对齐，不复制、不补空白。真实数量至少4且含本人主宠物时固定第4位；0～3及无本人时按03h§2.1。单屏不自动播放；多屏默认自动+手动，提供页码、上一屏/下一屏及暂停/继续。间隔/动画/恢复等待统一引用10a§2.5；手势、焦点、弹层、离屏、后台与减少动态效果按03h§2.2。显式暂停不因空闲、刷新、返回自动解除。公开授权失效优先撤销展示。

## 8. 上门喂养

### 8.1 顶部操作

发布需求为主操作，我的需求为次操作，更多需求进入公开列表。按钮视觉高度参考36px，热区至少target.min；窄屏可换行，保留全部入口。

### 8.2 单卡

正常字号默认最小内容高度132px，无最大高度限制，长地点/状态和大字号自然增高。标题推荐12字，地点摘要推荐12字但真实城市/区县优先完整，要求摘要推荐18字。预算使用克制暖色强调，单位必须如实。主状态仍为待接单、已接单待门店对接、进行中、已完成；取消历史状态。进行中必须有真实阶段副文案：门店协调中、已确认等待服务、正在服务，按03j底层状态映射，按钮仍由实际状态控制。不能以“进行中”暗示已经上门服务。

### 8.3 本地为空

当前城市无真实公开需求时，随机补充其他城市仍可公开的真实需求，推荐2～3条，标注真实城市/区县，不伪造本地需求。全平台均无公开需求时才显示真正Empty及发布需求引导。推荐失败与成功无数据分开处理。

## 9. 精选商品

正常字号每屏建议3张，窄屏/大字号可改宽卡横向浏览，不强缩内容。三列宽度复用7.1公式，正常字号默认最小内容高度156px，长内容自然增高；图片区参考86px高，加载前保留比例。名称推荐8字/2行，副描述10字/1行，完整名称详情可读。重点为图片、名称、参考价和必要库存状态；不堆叠SKU、物流、地址，不提供线上支付误导按钮。

## 10. 首页底部微信 Banner 广告横幅

### 10.1 位置

`home_bottom_banner`固定在精选商品之后、底部导航之前的正常内容流，不覆盖正文。不是顶部品牌或启动封面，不属于激励广告。

### 10.2 布局

水平宽度适配内容区，实际高度按微信组件/SDK返回，不硬编码创意比例。与精选商品保持space.6，距导航/安全区建议12～16px，最终按真实组件尺寸校准。底部占位按实际导航高度+安全区+space.4计算，系统已预留空间不重复累加，广告完整区域可滚动至导航之上。顾问不得覆盖广告主要点击区。

### 10.3 加载状态

至少disabled/loading/loaded/no_fill/failed。disabled/no_fill/failed自动收起，不留大块永久空白。loading仅使用组件允许的预估占位，不伪造广告素材；实际尺寸返回后更新，按10a§13.4保留阅读锚点。不能使用户按下位置变成其他业务按钮；同轮收起后不反复展开重试，重新进入/合法刷新按广告策略处理。失败不影响其他首页业务。

### 10.4 调试

H5/测试允许明确标识的广告占位，模拟加载成功、无填充、失败、关闭和收起布局。生产必须真实微信广告组件，不得Mock冒充曝光/收入；广告单元ID和开关配置化，不散落硬编码。业务规则见03o，平台支持能力需按DEC-AD-PLATFORM-01验证。

## 11. 养宠顾问悬浮入口

产品确认方案A圆形。视觉尺寸参考52×52px，默认左侧中下安全区域，边缘8～12px，吸附使用motion.snap。真实热区至少target.min。允许拖动并吸附左右，提供可见调整位置/左右移位/重置替代操作，减少动态效果立即定位。避让微信胶囊、导航、固定主操作、广告和安全区，无安全位置时临时隐藏。

只在03l规定的有效付费门店权益、门店开启、本店Customer及服务端资格均成立时显示；无资格不显示可用入口，切店立即刷新。资格、问答额度和广告权益不由本UI文档定义。

## 12. 底部导航

固定预约/首页/我的，选中brand.strong，未选中中性文字，圆角线性图标，不做夸张悬浮中央按钮。实际热区至少target.min，底部安全区适配一次；视觉高度与安全区按真机适配，不以固定页面高度裁切内容。

## 13. 文案长度基线

| 区域 | 正常字号编排建议 |
|---|---|
| 门店名称 | 10字内 |
| 顶部副标题 | 16字内 |
| Banner主标题 | 8～12字 |
| 当前服务标题 | 14字内 |
| 最新动态摘要 | 16字内 |
| 宠物昵称 | 4字内 |
| 上门喂养标题 | 12字内 |
| 地点摘要 | 12字内，真实城市/区县优先 |
| 上门喂养要求 | 18字内 |
| 商品名 | 8字内 |
| 商品副描述 | 10字内 |
| 普通按钮 | 4～6字 |

以上为编排建议，不是数据校验长度。长文按10a换行或详情全文，不因参考尺寸吞掉状态、金额、实际地点、必要错误或业务操作。

## 14. 状态标签

共享字体、颜色、圆角、间距只用10a Token。正常字号最小高度24px，随内容增高，水平内边距参考10px、圆角radius.control，type.label；长状态可独占一行或自然换行浅底文字条，不能截断完整状态。具体业务状态按03d/03j等权威模块，不由UI创造。低饱和蓝/绿仅作小面积语义，不形成绿色品牌基底。

## 15. 首页视觉权重与首屏任务

当前服务为最高业务/视觉权重，其次交友、上门喂养、顶部品牌Banner、商品、底部曝光广告。品牌图片应提升气质但不能压过当前服务。正常首屏不是按各模块百分比硬切布局，而是优先保留业务状态和主操作。

有服务时采用紧凑品牌变体。约定最小支持屏幕320×568、100%字号下首屏须露出第一条服务状态及主操作；150%/200%字号允许纵向滚动但内容、状态和操作完整可达，不为凑首屏缩字。无服务时完整品牌Banner与预约引导自然排布。布局、内容和交互均须实际验证，不能只凭参考卡高判定通过。

## 16. 故障隔离

任何首页模块失败只局部降级：广告收起、顾问资格/服务失败局部处理、交友和上门喂养各自错误，当前服务失败不能整页白屏。Loading/刷新/Empty/No Results/Error/Disabled/Busy和安全锚点按10a§13；首次加载、已确认空数据和刷新失败不得混为一态。启动广告失败按03p恢复原业务目标，而非强制回首页。

## 17. 需求 / UI 变更记录

本节仅供历史追溯，现行规则以正文及权威模块为准。

### 2026-09-06：首页底部广告

新增home_bottom_banner，位于精选商品后、导航前，用于微信曝光变现，配置化、可调试、失败局部收起。影响首页布局、广告SDK、顾问避让及运营统计。

### 2026-09-06：养宠顾问付费门店显示

原默认全局入口被条件式入口替代，门店权益、门店开启及本店Customer由03l校验，不在未付费门店展示可用入口。

### 2026-09-06：启动封面与首页解耦

launch_cover_ad发生在首页之前，不占首页布局；目标恢复以03p现行规则为准。

### 2026-09-08：紧凑品牌变体与移动适配

有服务紧凑、无服务完整品牌Banner；通用Token由10a管理，长文/字号/热区/安全区自然适配，社交数量和暂停按03h，启动目标按03p。

### 2026-09-08：规范等级和单一来源整理

首页专属默认/最小高度与通用Token分离，删除“参考最小”等混合措辞；保留320px三列自适应公式，不再硬编码104px；进行中增加真实阶段副文案，权限失效与布局稳定优先级统一引用10a§13.4。此变更不修改业务状态机或广告权益。
