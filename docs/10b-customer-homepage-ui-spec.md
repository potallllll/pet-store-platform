# 10B 客户端首页 UI 最终设计规格

> 状态：已确认基线，持续细化
> 所属阶段：10 UI / Design System（提前与阶段 04 并行）
> 版本：V1.0

## 1. 文档职责

本文件用于收口客户端首页的具体视觉与布局规格，是 `10a-customer-ui-design-system.md` 的首页专项细化。

业务逻辑仍以 `03-customer-miniapp.md`、`03a`～`03o` 为准；本文件不得自行修改业务状态、广告权益、隐私、订单、积分或多租户规则。

---

## 2. 首页最终结构

首页从上到下固定为：

1. 顶部门店栏
2. 顶部品牌 / 生活方式 Banner
3. 当前服务
4. 宠物交友
5. 上门喂养
6. 精选商品
7. 首页底部微信 Banner 广告横幅
8. 底部导航
9. 全局养宠顾问悬浮入口

底部一级导航仍只有：预约 / 首页 / 我的。

---

## 3. 页面栅格与间距

以 375px 宽设计基准为主要参考，正式小程序按实际设备宽度自适应。

- 页面左右边距：16px
- 顶部安全区以下首个内容起始：约 12px
- 主模块之间垂直间距：24px
- 模块标题与内容间距：12px
- 卡片内部边距：14～16px
- 横向卡片间距：10px
- 小标签间距：6px
- 同组按钮间距：8～10px
- 采用 4px 基础间距栅格，避免随意出现非体系值

---

## 4. 顶部门店栏

- 高度参考：52px
- 左侧：门店头像（如使用）+ 门店名称 + 可选轻副标题
- 门店头像参考：32×32px
- 门店名称：20px / 600，最多约 10 个中文字符，超出省略
- 副标题：13px / 400，最多约 16 个中文字符，超出省略
- 右侧只保留消息入口
- 消息按钮触控容器约 40×40px
- 未读可使用红点 / 数量
- 不在首页顶部同时放搜索、扫码等入口

---

## 5. 顶部品牌 / 生活方式 Banner

该 Banner 是产品 / 门店氛围视觉，不是微信广告位。

### 5.1 尺寸

- 宽度：填满页面内容宽度
- 高度参考：164px
- 圆角参考：20px
- 文案区约 42%，宠物主图区约 58%

### 5.2 文案

- 主标题：28px / 700，最多 2 行，推荐 8～12 个中文字符
- 副标题：13px，最多 1 行
- CTA 高度约 34px，文案推荐 4～6 个中文字符

示例：

> 陪伴
> 让生活更温暖

顶部品牌 Banner 可以轮播，但建议最多 3 张；精确轮播参数后续冻结。

---

## 6. 当前服务

当前服务是首页最高视觉 / 业务权重模块。

### 6.1 卡片高度

- 洗护 / 美容：参考 148px
- 寄养：参考 164px

### 6.2 内容

- 宠物头像参考 76×76px
- 标题：宠物名 + 服务类型，16px / 700，最多约 14 个中文字符
- 日期 / 状态 / 最新动态等正文 13～14px
- 最新动态摘要最多约 16 个中文字符
- 主按钮高度参考 38px，文案 4～6 个中文字符

寄养卡至少显示：日期范围、当前第几天、最新动态、今日动态数量、新媒体提示和“查看寄养动态”。

---

## 7. 宠物交友

### 7.1 单卡尺寸

375px 基准下参考：

- 单卡宽度约 104px
- 单卡高度约 166px
- 圆角 16px
- 图片区约 104×104px

### 7.2 卡片结构

固定核心信息：

1. 宠物主图
2. 宠物昵称
3. 热度
4. 卡片底部浅色“可发送邀请”能力标签（仅符合条件时）

昵称推荐最多 4 个中文字符。

热度不使用爱心 / 点赞图标语义；展示例如：

> 热度 286

热度基于最近 7 天有效点击及当前门店 7 日排名，前端只展示服务端结果。

### 7.3 轮播

- 每屏 3 只
- 一轮最多 12 只
- 自动轮播 + 手动滑动
- 自己的主宠物固定第 4 位
- 用户操作期间自动轮播让位

精确秒数暂不冻结。

---

## 8. 上门喂养

### 8.1 顶部操作

- 发布需求：主操作
- 我的需求：次操作
- 右侧“更多需求”进入公开列表
- 操作按钮高度参考 36px

### 8.2 单卡

- 高度参考 132px；信息较多时最高建议约 138px
- 标题最多约 12 个中文字符
- 地点最多约 12 个中文字符
- 要求摘要最多约 18 个中文字符
- 预算使用明显但克制的暖橙 / 杏棕强调

客户端主状态：

1. 待接单
2. 已接单待门店对接
3. 进行中
4. 已完成

取消只用于历史 / 终止状态展示。

### 8.3 本地为空

当前城市无真实可公开需求时：

- 随机补充其他城市真实公开需求；
- 必须显示真实城市 / 区县；
- 不得伪造本地需求；
- 推荐 2～3 条；
- 如果全平台都无可公开需求，再展示真正 Empty State 和“发布需求”。

---

## 9. 精选商品

- 每屏建议 3 张
- 横向滑动
- 单卡参考 108×156px
- 圆角 16px
- 图片区约 86px 高
- 商品名最多约 8 个中文字符 / 2 行内
- 副描述最多约 10 个中文字符 / 1 行
- 首页只突出图片、商品名、参考售价和必要库存状态
- 不展示复杂 SKU / 物流 / 收货地址

---

## 10. 首页底部微信 Banner 广告横幅

这是用于微信广告曝光变现的正式广告位，与顶部品牌 Banner 完全不同。

### 10.1 位置

固定在：

> 精选商品之后 → 微信 Banner 广告横幅 → 底部导航

使用 placement：

`home_bottom_banner`

### 10.2 布局

- 广告位属于正常内容流，不覆盖正文
- 水平宽度适配页面内容宽度
- 广告实际高度根据微信广告组件 / SDK 返回适配，不硬编码单一创意比例
- 与精选商品上方保持约 24px 模块间距
- 与底部导航 / 安全区之间建议至少保留 12～16px 可用间距（最终结合真实广告组件尺寸校准）
- 养宠顾问不得覆盖广告主要点击区域

### 10.3 加载状态

至少覆盖：

- disabled
- loading
- loaded
- no_fill
- failed

`disabled / no_fill / failed` 时自动收起，不留大块永久空白。

广告失败不得影响首页任何业务模块。

### 10.4 调试

开发 / H5 原型应提供清晰的“广告调试占位”状态，用于模拟：

- 加载成功
- 无填充
- 加载失败
- 已关闭
- 收起后页面布局

正式生产必须切换为真实微信广告组件，不允许 Mock 冒充真实广告。

广告单元 ID / 开关必须配置化，不散落硬编码在 UI 组件中。

---

## 11. 养宠顾问悬浮入口

产品方确认采用方案 A：圆形悬浮按钮。

- 尺寸参考 52×52px
- 默认左侧中下安全区域
- 距边参考 8～12px
- 不遮挡底部导航、微信系统区域、首页底部 Banner 广告
- 可拖动
- 松手吸附最近左 / 右侧
- 吸附动效参考约 200ms，后续可 Token 化
- 采用柔和杏橙 / 奶油暖色，不使用绿色为基底或紫蓝科技发光

---

## 12. 底部导航

固定：

> 预约 | 首页 | 我的

- 当前项：暖橙 / 杏棕强调
- 未选中：暖灰中性色
- 线性圆角图标
- 触控高度满足约 44px 以上
- 适配 `safe-area-inset-bottom`

---

## 13. 文案长度基线

| 区域 | 建议长度 |
|---|---|
| 门店名称 | 10 字内 |
| 顶部副标题 | 16 字内 |
| Banner 主标题 | 8～12 字 |
| 当前服务标题 | 14 字内 |
| 最新动态摘要 | 16 字内 |
| 宠物昵称 | 4 字内 |
| 上门喂养标题 | 12 字内 |
| 上门喂养要求摘要 | 18 字内 |
| 商品名 | 8 字内 |
| 商品副描述 | 10 字内 |
| 普通按钮文案 | 4～6 字 |

首页负责快速浏览和进入详情，不在首页展示长篇正文。

---

## 14. 状态标签

统一参考：

- 高度约 24px
- 水平内边距约 10px
- 圆角约 12px
- 字号约 12px / 500
- 原则上单行，不做两行状态胶囊

允许低饱和状态色：

- 待接单 / 等待：浅橙
- 已接单待门店对接：浅米棕
- 进行中：低饱和蓝
- 已完成：低饱和灰绿 / 鼠尾草色
- 已取消：灰

页面整体仍不是绿色基底。

---

## 15. 首页视觉权重

优先级：

1. 当前服务
2. 宠物交友
3. 上门喂养
4. 顶部品牌 Banner
5. 精选商品
6. 底部微信 Banner 广告（商业曝光位，但不压过核心业务）

Banner 广告需要真实曝光机会，但不得通过遮挡核心业务、强制弹出或破坏交互来获得曝光。

---

## 16. 故障隔离

任何一个首页模块失败只局部降级。

尤其：

- 微信 Banner 广告失败 → 广告收起，其他业务继续；
- 养宠顾问失败 → 顾问入口提示不可用；
- 宠物交友失败 → 仅交友区域错误；
- 上门喂养失败 → 不影响商品和当前服务；
- 当前服务失败 → 不得导致整页白屏。

---

## 17. 需求 / UI 变更记录

### 2026-09-06：首页底部新增微信 Banner 广告位

【UI / 产品变更】

- 原结构：精选商品后直接进入底部导航。
- 新结构：精选商品后新增 `home_bottom_banner` 微信 Banner 广告横幅，再进入底部导航。
- 目的：用于微信广告曝光变现，并提供配置化开关和可调试状态。
- 影响范围：首页高度 / 间距、广告 SDK、底部安全区、养宠顾问避让、H5 调试原型、平台广告配置和后续收益监控。
