# 03N 客户端「页面蓝图扩展：上门喂养 / 积分 / 养宠顾问」

> 状态：已确认子模块
> 所属阶段：03 客户端微信小程序
> 版本：V1.0

## 1. 文档职责

本文件是 `03i-customer-screen-blueprint.md` 的新增功能扩展，用于承接 2026-09-06 后确认的：

- 上门喂养需求市场
- 平台积分 / 每日签到 / 积分商城
- 养宠顾问
- 统一激励广告权益

本文件只扩展新增页面、入口和验收场景，不改变 `03i` 已确认的其他页面结构、N 组对比、宠物交友、钱包和 AI 洗护报告规则。

对于本文件明确涉及的新功能，如与 `03i` 旧首页顺序或旧“无积分”假设不一致，以本文件与 `03j`～`03m` 最新已确认规则为准。

## 2. 首页顺序变更

首页核心信息顺序更新为：

1. 当前门店
2. 当前服务
3. 上门喂养
4. 宠物交友
5. 推荐商品

上门喂养属于平台级公开需求市场，但发布时绑定当前门店；不新增底部一级导航。

## 4. 首页「上门喂养」区域

首页上门喂养区域至少应提供：

- 当前公开需求摘要
- 时间
- 模糊地点
- 每日预算
- 状态
- “查看更多”
- “发布需求”

公开区域不得显示精确住宅地址、手机号、微信等敏感信息。

## 5. 上门喂养发布页

正常发布路径尽量保持连续式：

选择宠物
→ 日期范围
→ 每日时间 / 次数
→ 地点
→ 每日预算
→ 喂养要求
→ 发布

发布成功页至少提供：

- 查看需求
- 分享到微信 / 群

## 6. 接单详情

需求详情至少展示：

- 宠物摘要
- 日期范围
- 每日时间
- 模糊地点
- 每日预算
- 喂养要求
- 当前状态
- 我要接单（符合条件时）

接单成功后显示：

> 已有人接单，等待门店对接

不得在接单前公开发布者精确联系方式。

## 7. “我的”积分入口

“我的”会员资产摘要卡保持原有四项资产信息，不加入积分。

积分作为独立平台权益入口，至少展示：

- 当前积分
- 今日是否已签到
- 积分商城入口

不把积分混入“我的钱包”。

## 8. 每日签到交互

正常路径：

点击「签到」
→ 激励广告
→ 完整观看并验证成功
→ 签到成功
→ 展示今日获得 N 积分（1～10）
→ 更新本周累计进度

完整一周 7 天签到时，本周累计展示必须精确为 50 分。

中途退出广告：

- 不显示签到成功
- 不增加积分

## 9. 积分商城

商城至少区分：

- 优惠券 / 虚拟权益
- 实物奖励

实物兑换路径：

选择奖励
→ 选择领取门店
→ 确认消耗积分
→ 待总仓发货
→ 已发往门店
→ 待自提
→ 已领取

客户端不建设快递到家、收货地址、运费或物流配送到用户页面。

## 10. 养宠顾问悬浮入口

- 默认位于左侧安全区域。
- 支持拖动。
- 松手后吸附最近左 / 右边缘。
- 不遮挡底部导航和微信系统区域。
- 大部分正常客户端页面均可显示；涉及全屏沉浸式媒体 / 广告等场景可按 UI 安全需要暂时隐藏。

## 11. 养宠顾问首次进入

首次点击：

养宠顾问悬浮按钮
→ 介绍弹窗
→ 关闭 / 开始咨询
→ AI 聊天页

后续进入默认直接聊天，可从“关于养宠顾问”重新查看介绍。

## 12. 养宠顾问次数状态

客户端需要能正确表达：

- 前三次免费
- 剩余免费次数
- 已用完，需要观看广告
- 广告成功后新增 3 次额度
- AI 失败未扣次数

不得只在前端本地计算剩余次数，最终状态以服务端为准。

## 13. 新增关键验收场景

### C-FEED-01：发布并分享

- 完成上门喂养发布。
- 发布成功后可分享到微信群。
- 分享深链进入当前需求。

### C-FEED-02：公开隐私

- 所有用户可浏览。
- 只显示模糊地点。
- 不显示门牌号、手机号、微信。

### C-FEED-03：接单与门店对接

- 第一个接单者成功锁定。
- 需求显示等待门店对接。
- 只通知发布时绑定门店。

### C-POINTS-01：签到

- 完整广告后随机获得 1～10 分。
- 同日不可重复签到。

### C-POINTS-02：完整周 50 分

- 模拟周一至周日连续完成签到。
- 7 次单日奖励均在 1～10。
- 总计严格 50。

### C-POINTS-03：实物自提

- 兑换实物并选择门店。
- 能展示待总仓发货、已发往门店、待自提、已领取状态。

### C-ADVISOR-01：悬浮吸附

- 拖动悬浮按钮。
- 松手后吸附最近边缘。

### C-ADVISOR-02：前三次免费 + 广告解锁

- 前三次成功问答免费。
- 第 4 次前触发广告。
- 广告成功后获得 3 次有效提问。

### C-ADVISOR-03：AI失败不扣额度

- 模拟 AI 错误。
- 剩余额度不减少。

## 14. 原型 / H5 新增验收范围

后续生成完整客户端 H5 / UI 原型时，除 `03i` 原有矩阵外，必须覆盖：

|---|---|---|---|
| C-FEED-01 | 上门喂养发布 | 时间、地点、每日预算、要求 | 发布 / 分享 |
| C-FEED-02 | 上门喂养详情 | 模糊地址、状态 | 接单 |
| C-FEED-03 | 已接单 | 等待门店对接 | 状态展示 |
| C-POINTS-01 | 积分中心 | 当前积分、签到 | 广告完成 / 失败模拟 |
| C-POINTS-02 | 周积分 | 每日随机值、本周累计 | 7 天合计 50 验收 |
| C-POINTS-03 | 积分商城实物 | 奖励、门店、自提状态 | 兑换 / 门店选择 |
| C-ADVISOR-01 | 全局悬浮顾问 | 悬浮入口 | 拖动 + 自动吸附 |
| C-ADVISOR-02 | AI聊天 | 免费 / 广告额度 | 提问 / 广告解锁 |

## 15. 需求变更记录

### 2026-09-06：扩展客户端页面蓝图

【需求变更】

- 原规则：首页顺序为当前门店 → 当前服务 → 宠物交友 → 推荐商品；客户端无积分体系，也无全局养宠顾问和平台上门喂养市场。
- 新规则：首页在当前服务后新增上门喂养；“我的”新增独立积分中心；客户端加入全局可拖动、自动吸附的养宠顾问；完整原型必须覆盖对应新增验收场景。
- 影响范围：首页顺序、页面地图、UI / Design System、H5 / 原型验收、Codex 客户端开发输入。
