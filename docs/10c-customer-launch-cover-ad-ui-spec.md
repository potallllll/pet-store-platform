## 1. 文档职责

本文件用于定义 `03p-customer-launch-cover-ad.md` 的客户端展示层和调试表现。

该页面 / 覆盖层发生在本次目标业务之前；没有明确目标时衔接首页，不改变 `10b-customer-homepage-ui-spec.md` 的首页模块顺序。

## 2. 启动流程

```text
小程序启动 / 符合频控的重新进入
↓
保存并校验本次外部目标 / 原页面及门店上下文
↓
检查启动前已知的有效有限等待预算
├─ 无有效预算 → 恢复目标（配置可后台读取）
└─ 有有效预算 → 读取 launch_cover_ad 配置（开始统一计时）
   ├─ disabled / 过期 / 无有效配置 / 读取超时 → 恢复目标
   └─ 请求主素材
      ├─ 加载成功 → 展示封面广告
      │             ↓
      │        自动结束 / 用户跳过 / 官方广告关闭 → 恢复目标
      └─ 无填充 / 加载失败
         ├─ 配置有效兜底且等待预算未耗尽 → 最多一次兜底
         │  ├─ 成功 → 展示封面广告 → 结束 / 关闭 → 恢复目标
         │  └─ 失败 / 过期 / 超时 → 恢复目标
         └─ 未配置兜底 / 等待预算耗尽 → 恢复目标

恢复目标
├─ 本次有效外部目标 → 按需登录 / Customer 校验后进入原目标
├─ 无新外部目标、后台回前台 → 原页面 / 同一会话未提交内容
├─ 无明确目标且有有效门店 → 首页
└─ 需要门店但没有有效门店 → 扫码 / 选店，保留原目标
```

页面内部 Tab / 二级页面跳转不重复展示。

本次有效扫码 / 门店深链优先于历史门店。平台公开详情不强制切到发布门店；私有业务重新鉴权后才展示。目标失效或无权限时展示具体原因及返回入口，不伪装为已成功到达目标。完整路由与等待规则见 `03p`、`03g`。

等待预算必须在请求配置前从已确认版本配置或本地已验证配置取得；没有预算立即恢复业务。远端响应不得延长本次截止。配置读取、主素材和一次兜底共用同一加载等待上限；fallback 不重置计时。用户关闭或已恢复业务后，不显示任何迟到素材。加载等待上限和展示时长分开控制，具体运营数值遵循 `03p` 的 `DEC-LAUNCH-01`，UI 不编造默认秒数。

## 3. 自定义图片模式

- 图片铺满可用启动广告视觉区域，按不同手机比例做 `cover` / 安全裁切。
- 核心 Logo、价格、二维码、文字、人物 / 宠物脸等重要内容必须保留在安全区。
- 顶部系统状态区和微信系统 UI 不得被伪造成素材的一部分。
- 页面可使用轻量“广告” / “推广”来源标识，具体展示由后续运营合规规则确认。
- 跳过 / 关闭按钮位置统一在右上安全区域，不与微信系统胶囊冲突。
- 倒计时、允许跳过时机和最大展示时长由后台配置，不写死具体秒数。

---

## 4. 自定义视频模式

- 视频优先使用竖屏适配素材；横屏素材必须有明确裁切 / 留白策略。
- 播放过程中不得出现无法退出的死锁状态。
- 网络慢 / 首帧无法在剩余加载预算内准备时，按已配置的一次兜底处理或恢复目标，不无限等待空白帧。
- 是否静音、是否自动播放、跳过策略按微信实际能力和后台配置执行。
- 视频结束后按配置自动恢复目标，不重复停留空白帧。

---

## 5. 微信官方广告模式

- 使用官方广告组件真实渲染。
- 不在其点击层上覆盖自定义按钮、养宠顾问或其他可点击业务控件。
- 官方广告关闭后恢复目标；无填充 / 加载失败仅按已配置的一次兜底处理并受统一等待上限约束，之后恢复目标。
- H5 / UI 原型只做明确标注的模拟占位，不冒充真实官方广告。

---

## 6. 视觉关系

启动封面广告可以拥有独立广告素材风格，不强制套用客户端暖色卡片 Design System；但外围控制层仍需保持：

- 跳过 / 关闭按钮清晰；
- 状态文字易读；
- 不伪造系统控件；
- 不使用会误导为业务主按钮的元素；
- 加载失败不展示空白全屏。

自定义平台品牌封面如果不是商业广告，可按运营内容使用；如果作为商业推广素材，后续需按实际投放要求处理广告标识。

---

## 7. 调试面板 / H5 原型

开发版原型建议提供以下模式切换：

- 图片
- 视频
- 微信广告模拟
- Disabled
- No Fill
- Failed
- Expired

并提供：

- 跳过
- 自动结束
- 素材替换模拟
- 频控命中 / 未命中
- 消息 / 分享 / 扫码目标、后台原页面、登录后目标恢复
- 无有效门店、目标失效 / 无权限
- 一次兜底、统一加载等待超时、迟到回调

所有调试按钮必须仅存在于开发 / H5 环境，正式小程序不得向普通用户暴露。

---

## 8. 与目标业务 / 首页的衔接

封面结束后优先恢复本次目标业务 / 后台原页面；登录后继续同一目标。没有明确目标且门店有效时进入当前正常首页：

> 顶部门店栏 → 品牌 Banner → 当前服务 → 宠物交友 → 上门喂养 → 精选商品 → 首页底部微信 Banner → 底部导航

养宠顾问只有当前门店具有有效付费权益并向本店客户开放时才出现；它不在启动封面广告期间悬浮显示。

---

## 9. 验收

- 图片 / 视频 / 微信广告三种模式都能独立切换。
- 替换图片 / 视频不需要改首页代码。
- 广告失败 / 无填充不会卡在启动层。
- 页面内部导航不会重复展示。
- 进入首页后布局与首页 UI 规格一致。
- 启动封面期间不显示养宠顾问悬浮按钮。
- 分享需求、消息详情、扫码目标在广告成功 / 失败 / 关闭后仍可正确到达，必要身份验证不会吞掉目标。
- 后台恢复保留原页面；无有效门店提供扫码 / 选店；无权限目标展示原因与返回入口。
- fallback 最多一次，不延长统一加载等待计时；超时或业务已恢复后迟到素材不重新弹出。
