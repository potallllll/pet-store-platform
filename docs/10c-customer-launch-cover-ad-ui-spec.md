# 10C 客户端启动封面广告 UI 规格

> 状态：已确认基线，持续细化
> 所属阶段：10 UI / Design System（提前与阶段 04 并行）
> 版本：V1.0

## 1. 文档职责

本文件用于定义 `03p-customer-launch-cover-ad.md` 的客户端展示层和调试表现。

该页面 / 覆盖层发生在正式首页之前，不改变 `10b-customer-homepage-ui-spec.md` 的首页模块顺序。

---

## 2. 启动流程

```text
小程序启动 / 符合频控的重新进入
↓
读取 launch_cover_ad 配置
↓
disabled / 无有效素材 / 无填充 / 加载失败
├─ 是 → 直接进入首页
└─ 否 → 展示封面广告
           ↓
       自动结束 / 用户跳过 / 官方广告关闭
           ↓
         进入首页
```

页面内部 Tab / 二级页面跳转不重复展示。

---

## 3. 自定义图片模式

- 图片铺满可用启动广告视觉区域，按不同手机比例做 `cover` / 安全裁切。
- 核心 Logo、价格、二维码、文字、人物 / 宠物脸等重要内容必须保留在安全区。
- 顶部系统状态区和微信系统 UI 不得被伪造成素材的一部分。
- 页面可使用轻量“广告” / “推广”来源标识，具体展示由后续运营合规规则确认。
- 跳过 / 关闭按钮位置统一在右上安全区域，不与微信系统胶囊冲突。
- 倒计时、允许跳过时机和最大展示时长由后台配置，不写死具体秒数。

---

## 4. 自定义视频模式

- 视频优先使用竖屏适配素材；横屏素材必须有明确裁切 / 留白策略。
- 播放过程中不得出现无法退出的死锁状态。
- 网络慢 / 首帧长期无法加载时使用封面图或直接降级进入首页。
- 是否静音、是否自动播放、跳过策略按微信实际能力和后台配置执行。
- 视频结束后按配置自动进入首页，不重复停留空白帧。

---

## 5. 微信官方广告模式

- 使用官方广告组件真实渲染。
- 不在其点击层上覆盖自定义按钮、养宠顾问或其他可点击业务控件。
- 官方广告关闭 / 无填充 / 失败后直接进入首页。
- H5 / UI 原型只做明确标注的模拟占位，不冒充真实官方广告。

---

## 6. 视觉关系

启动封面广告可以拥有独立广告素材风格，不强制套用客户端暖色卡片 Design System；但外围控制层仍需保持：

- 跳过 / 关闭按钮清晰；
- 状态文字易读；
- 不伪造系统控件；
- 不使用会误导为业务主按钮的元素；
- 加载失败不展示空白全屏。

自定义平台品牌封面如果不是商业广告，可按运营内容使用；如果作为商业推广素材，后续需按实际投放要求处理广告标识。

---

## 7. 调试面板 / H5 原型

开发版原型建议提供以下模式切换：

- 图片
- 视频
- 微信广告模拟
- Disabled
- No Fill
- Failed
- Expired

并提供：

- 跳过
- 自动结束
- 素材替换模拟
- 频控命中 / 未命中

所有调试按钮必须仅存在于开发 / H5 环境，正式小程序不得向普通用户暴露。

---

## 8. 与首页的衔接

封面结束后进入当前正常首页：

> 顶部门店栏 → 品牌 Banner → 当前服务 → 宠物交友 → 上门喂养 → 精选商品 → 首页底部微信 Banner → 底部导航

养宠顾问只有当前门店具有有效付费权益并向本店客户开放时才出现；它不在启动封面广告期间悬浮显示。

---

## 9. 验收

- 图片 / 视频 / 微信广告三种模式都能独立切换。
- 替换图片 / 视频不需要改首页代码。
- 广告失败 / 无填充不会卡在启动层。
- 页面内部导航不会重复展示。
- 进入首页后布局与首页 UI 规格一致。
- 启动封面期间不显示养宠顾问悬浮按钮。
