# PawDays 客户端＋店员端交互验收原型

本目录是与当前正式需求同步的静态 H5 验收资产，可直接打开 `dist/index.html`，或用任意静态服务器运行 `dist/`。

## 权威边界

- 正式业务规则只以仓库根 `AGENTS.md`、`docs/README.md` 及其指向的当前有效文档为准。
- 本原型用于核对页面、入口、文案、基础状态和交互，不新增业务规则。
- 可点击不代表小程序后端、微信登录／广告、权限、支付、并发或数据持久化已经实现。
- 若原型与正式文档冲突，先修正文档冲突，再同步原型；不得反向用原型覆盖正式规则。

## 本轮重点

- 客户端首页顶部唯一门店栏、正文无品牌 Banner、紧凑消费争议、“附近小区的人都在买”。
- 寄养加餐位于寄养详情第二行、时间轴上方，并按普通商品需求处理。
- 店员工作台和洗美页统一使用“临时开单／会员开单”。
- 临时开单填写手机号或微信号；会员开单下拉选择本店已有顾客。
- 洗美详情提供皮肤、耳道、眼睛、口腔、指甲、毛发、全身七组洗护前／后选填照片入口。
