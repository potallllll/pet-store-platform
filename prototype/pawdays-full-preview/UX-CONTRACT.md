# PawDays H5 预览交互契约

## 权威来源

- 业务规则：`potallllll/pet-store-platform` GitHub `main` 的正式 `docs/` 文件。
- 页面地图：`docs/03i-customer-screen-blueprint.md` 与 `docs/04-staff-miniapp.md`。
- 客户端视觉：`docs/10a`、`10b`、`10c`。
- 本文件只定义原型中的可观察行为，不新增业务政策。

| CRUD | 各业务页面的共享渲染器与应用状态仓库 | `dist/app.js` 中的 `state`、`renderPage` 与业务动作处理器 | 只允许业务规则明确的新增、修改、删除、恢复动作 | 重置演示后状态恢复；操作后页面与 Toast 同步更新 |
| Date | 浏览器原生日期控件 | 表单字段值与对应业务规则 | 显示格式可本地化，保存值统一为日期字符串 | 预约、寄养与查询筛选可选择并回显日期 |
| Form | 共享表单提交与字段错误模式 | `UX-CONTRACT.md` 表单规则及 `dist/app.js` 校验函数 | 不同业务只扩展字段，不改变错误反馈方式 | 空必填项提交会显示字段错误并聚焦第一项 |
| Scrollbar | 浏览器原生滚动容器，CSS 统一外观 | `dist/styles.css` 全局 scrollbar 规则 | 强制色彩模式回退系统样式 | 页面与列表可滚动，窄屏无横向页面溢出 |
| Select/Listbox | 浏览器原生 `select` | 当前表单选项数据 | 正式产品后续可替换为等价可访问组件 | 键盘可选择，值进入提交结果或筛选状态 |
| Toast | 应用根节点共享 Toast region | `dist/app.js` 的统一反馈函数 | success、error 与普通三种语义变体 | 操作后出现中文反馈，自动消失且不阻断操作 |

## 导航

- 客户端底栏固定为预约、首页、我的。
- 客户端首页顶部只保留当前门店名称、社区位置与小字号“切换门店”操作；正文不重复门店名称，也不在“当前服务”上方展示宣传 Banner。
- 客户端寄养详情顶部摘要之后第二行展示“寄养加餐”，并位于时间轴上方；它按普通商品需求处理，不表示已经投喂。
- 店员端底栏固定为工作台、业务、洗美、客户、我的。
- 原型控制台的端切换不改变业务数据；返回按钮回到当前端上一层。
- 每个页面更新 `document.title`，格式为“页面名 · PawDays 客户端/店员端”。

## 反馈与状态

- 所有动作通过共享 Toast 反馈；错误同时保留在对应页面或弹层内。
- 业务提交使用短暂 busy 状态并阻止重复提交。
- 删除、撤销、免单、核销等不可轻易恢复的动作使用应用内确认弹层，不调用浏览器原生对话框。
- 原型模拟动作会明确显示“演示数据已更新”，不声称调用真实后端。

## 表单

- 所有表单使用 `novalidate`，错误显示在字段附近并聚焦第一个错误项。
- 文本域禁止手动拖拽，保留足够高度。
- 原型接受系统原生 select/date 控件的弹出样式，属于明确的 native owner；产品正式实现可由后续店员 UI 规范收口。
- 图片上传在原型中只做本地文件名/预览模拟，不上传外部服务。
- 洗美详情的六个检查位置与全身均提供洗护前、洗护后照片入口，全部选填，可分次保存。

## 搜索与列表

- 本地假数据搜索即时执行，并提供独立清除按钮；不模拟远程请求，因此无需 300ms 网络防抖。
- 列表提供明确的空数据、无搜索结果和加载失败演示状态。
- 店员业务长列表在页面自然滚动，不强制固定视口表格。

## 权限与待决范围

- 原型可切换老板/员工视角；老板管理仅老板可见。
- 暂未开放短信、平台裁决、厂家邮件与 Web 后台录入等能力只展示说明，不提供假成功按钮。
- 店员端处于需求讨论阶段；未冻结的细节以“方案预览”标签展示。

## 可访问性

- 目标为 WCAG 2.2 AA 基线：语义按钮/链接、可见焦点、中文可访问名称、颜色外的文字状态、减少动态效果适配。
- 弹层打开后聚焦，Tab 在弹层内循环，Escape 关闭可取消弹层，关闭后恢复触发按钮焦点。
- 重要触控目标不小于 44×44px。

## 原型数据与恢复

- 所有数据仅保存在当前浏览器内存；刷新恢复初始演示数据。
- “重置演示”恢复全部假数据和导航。
- 任何原型成功都不代表小程序后端、权限、并发、微信广告或支付验收完成。
