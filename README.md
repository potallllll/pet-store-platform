# Pet Store Platform

面向社区型、小型宠物店的免费多商户 SaaS 经营管理平台。

## 项目组成

- 客户端微信小程序
- 店员端微信小程序（商户老板也可使用，并默认拥有全部店员权限）
- Web 管理后台
- 统一后端 API
- 统一数据库
- 多商户数据隔离体系

## 工作规则

1. 只有明确确认并同步到本仓库的需求才属于正式规格。
2. 已确认需求修改时必须记录原规则、新规则和影响范围。
3. 各端设计必须同时考虑多租户隔离、权限、数据库、财务审计和业务联动。
4. 阶段 13 完成 V1.0 需求冻结后，再生成 Codex Master Prompt 并进入正式开发。
5. Codex / 其他 AI 不得自行删减、改写或用 Mock/TODO 冒充已冻结需求。
6. 如果两个已确认规格存在无法同时满足的冲突，不得自行脑补，必须先提出并处理需求变更。
