# Pet Store Platform

统一的宠物门店数字化平台项目。

## 项目组成

- 客户端微信小程序
- 店长 / 员工端微信小程序
- Web 管理后台
- 统一后端 API
- 统一数据库

## 当前阶段

需求设计阶段。所有正式需求以 `docs/` 与 `specs/` 下的文档为准。

## 工作规则

1. 聊天中的想法不自动视为正式需求。
2. 只有明确确认后的需求才写入正式规格。
3. 所有核心功能必须同时考虑客户端、店长端、后台、后端、数据库与权限影响。
4. V1.0 需求冻结后，再生成 Codex Master Prompt。
5. Codex 根据完整规格执行开发，禁止自行删减已冻结需求。
