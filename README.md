# Pet Store Platform

面向社区型、小型宠物店的免费多商户 SaaS 经营管理平台。

项目包括客户端微信小程序、店员端小程序（老板也可使用）、Web管理后台、后端业务服务、数据库与多商户数据隔离体系。V1.0 当前约束一个Merchant对应一家Store；平台运营、门店经营和客户个人业务按正式权限及数据归属管理。
